# Agent Bento 项目概览

## 一句话

Agent Bento 是一个面向独居长者家庭的隐私优先照护概念：当家里出现异常安静时，先安排一次自然的人类上门确认，再根据结果通知家人。

## 用户问题

家人常常面对三个不理想的选择：持续打电话、安装侵入式摄像头，或在信息不足时直接升级为紧急事件。Agent Bento 展示了一个更温和的中间路径。

## 产品体验

1. 家庭活动处于正常状态。
2. 互动故事出现一段异常安静。
3. 系统请求便当配送员进行友好上门确认。
4. 长者作出回应，但仍等待确认。
5. 配送员确认安全，家庭界面恢复正常。

便当的价值不仅是配送食物，也提供一个自然、低压力的敲门理由。

## 当前真实边界

### 已实现

- 产品落地页和家庭仪表板
- 日本住宅示例户型图
- 可移动、支持键盘操作的 Wi-Fi 路由器标记
- 同一回放时钟驱动的照护故事
- 家庭状态、房间、照护记录和事件旅程
- 折叠的模拟 Wi-Fi 活动轨迹
- 浏览器本地设置保存

### 模拟

- Wi-Fi 活动信号
- 异常静止判断
- 便当下单、骑手接单和到达
- 长者回应、骑手确认和家庭通知

### 计划

- 经过校准的真实传感硬件
- 长者同意和设备管理
- 持久化事件状态和审计记录
- 真实配送与通知集成
- 失败重试、人工处理和现场验证

## 当前没有使用的能力

- 不调用云端模型服务
- 不分析用户上传的户型图
- 不提供自定义户型上传
- 不展示模型置信度、服务状态或临床生命体征

## 隐私与安全

- 公共原型不使用摄像头或麦克风录音。
- 传感、配送和通知均明确标记为模拟。
- 产品不提供诊断，也不应被描述为医疗设备。
- 真实部署必须先完成同意、校准、安全身份、审计和实地测试。

## 技术实现

- Next.js 16
- React 19
- TypeScript
- Vercel 部署
- SVG / CSS 模拟活动轨迹
- Node.js 测试与生产构建检查

仓库保留一个独立的实验性 RuView HTTP 桥接路由，用于未来硬件探索；它没有连接到公共家庭演示。

## 核心表达

> Notice unusual silence, send human care, and escalate only when needed.

中文可表达为：

> 发现异常安静，先送去人的关怀，只在必要时升级。
